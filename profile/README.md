## 📌 About This Organization

This GitHub organization contains the repositories created throughout the **CS3613 Introduction to Artificial Intelligence** module.

It is not limited to lecture notes. Separate repositories will be maintained for different areas of the module, including:

- Weekly learning notes
- Lecture and tutorial materials
- In-class activities
- Laboratory exercises
- Search and optimization implementations
- Logic and reasoning exercises
- Knowledge representation work
- Probabilistic reasoning activities
- Assignments
- Individual and group projects
- AI experiments
- Research and additional learning
- Revision resources
- Exam preparation

The main goal is to create a structured, version-controlled knowledge base that connects the theoretical foundations of artificial intelligence with practical implementations.

## 🎯 Objectives

This organization is designed to:

- Organize all CS3613-related work in one place

## 📝 Weekly Notes Workflow

Weekly learning notes are initially created and organized in **Notion**.

The completed notes are then maintained in a dedicated GitHub repository for:

- Long-term storage
- Version control
- Easy accessibility
- Continuous improvement
- Revision
- Linking notes with code and practical work

Each weekly note may include:

1. Lecture concepts
2. Simplified explanations
3. Important definitions
4. Diagrams and visual explanations
5. Algorithms and pseudocode
6. Step-by-step examples
7. Mathematical or logical explanations
8. In-class activities
9. Laboratory work
10. Questions and answers
11. Common mistakes and misconceptions
12. Additional research
13. Weekly summaries
14. Active-recall questions
15. Revision checkpoints

The notes are intended to evolve continuously rather than remain as static copies of lecture slides.
