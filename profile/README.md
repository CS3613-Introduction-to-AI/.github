# CS3613 Introduction to Artificial Intelligence

Central repository organization for academic coursework, laboratory implementations, weekly study notes, and assignments for CS3613 Introduction to Artificial Intelligence at the Department of Computer Science and Engineering, University of Moratuwa.

## Organization Repositories

- [CS3613-Weekly-Notes](https://github.com/CS3613-Introduction-to-AI/CS3613-Weekly-Notes): Comprehensive weekly lecture notes, algorithmic breakdowns, theoretical foundations, and active-recall revision checkpoints.
- [sri-lanka-tourism-ontology](https://github.com/CS3613-Introduction-to-AI/sri-lanka-tourism-ontology): Protégé 5 OWL 2 domain ontology, HermiT reasoning validation artifacts, and laboratory report for Sri Lankan tourism destinations and heritage sites.
- **Laboratories & Assignments**: Dedicated repositories will be added as practical exercises, search algorithms, and assignments are scheduled throughout the semester.
- [.github](https://github.com/CS3613-Introduction-to-AI/.github): Organization profile and workspace configuration.

## Module Documentation

Weekly learning notes are structured through Notion and maintained in GitHub for version-controlled, accessible reference. Each topic emphasizes foundational concepts, formalized problem definitions, algorithm design, and practical implementations.

## Engineering & Git Standards

- **Commit Conventions**: All commits adhere to Conventional Commits format (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`).
- **Branching Workflow**: Assignment and project deliverables utilize isolated task branches before merging into `main`.
- **Documentation**: All practical submissions maintain clear requirement traceability, verification evidence, and reproducible steps.
